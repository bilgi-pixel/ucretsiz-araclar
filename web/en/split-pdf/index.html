    How to split a PDF

    1. Drop a PDF into the box above or click "Choose PDF". The page count appears right away.
    2. Choose an action: extract a page range, split every N pages, delete pages, or save every page as its own file.
    3. For ranges, type page numbers such as "1-3, 5, 8-10". A trailing dash such as "4-" means page 4 through the last page. Pages are written in the order you type them, so "5, 1-2" puts page 5 first.
    4. Press "Split PDF". The tool builds each new file in turn and shows progress.
    5. Download the result. If the action created several files, use the button for each part or "Download all".

    Common reasons to split a PDF

    Sometimes a document contains far more than the person on the other end needs. You may have a 40-page scan of a lease but only need to send the signature page, or a bank statement bundle where just the latest month matters. Extracting only the relevant pages keeps private information private, makes attachments smaller and saves the recipient from hunting through a long file.

    Other times the problem is size. An application portal that accepts files up to a few megabytes will refuse a 60-page report, but accepts it in three parts. Splitting every 20 pages produces parts that each fit under the limit. Teachers split a scanned class set into one file per student, and researchers pull a single chapter out of a long paper for a colleague.

    Deleting pages is the mirror image: drop the blank page a scanner added, remove a cover sheet, or cut an outdated appendix. Because the tool copies the pages you keep exactly as they are, text remains selectable and images are not recompressed.

    Four ways to split

    Extract a page range creates one new PDF from the pages you list. It also works as a page re-orderer, because the order you type is the order you get.

    Split every N pages cuts the document into equal chunks; the last chunk simply holds the remainder. Files are named with the original name plus a part number, such as "report-1.pdf".

    Delete pages keeps everything except the pages you list. The tool refuses to delete every page, since an empty PDF is not valid.

    One PDF per page exports each page as a separate file, which is handy for scanned batches of single-page forms or receipts.

    After splitting you can recombine selected parts with Merge PDF, or shrink a part that is still too large with Compress PDF. If the file asks for a password, it cannot be opened here; remove the password in a program where you know it and try again.

    Why use this splitter?

    Frequently asked questions

    Is my PDF uploaded to split it?

    No. The file is opened and split in your browser, and nothing is sent anywhere. The tool keeps working if your connection drops after the page has loaded.

    How do I extract just a few pages from a PDF?

    Choose "Extract a page range", type the pages such as "2, 4-6" and press Split PDF. You get one new PDF containing exactly those pages.

    Can I change the order of pages?

    Yes. In extract mode pages come out in the order you type them, so "3, 1, 2" produces a document that starts with page 3.

    How do I split a large PDF so each part fits an upload limit?

    Use "Split every N pages" with a number that gives parts under the limit, then check the sizes. If a part is still too big, run it through Compress PDF.

    Can I delete a page from a PDF?

    Yes. Choose "Delete pages", enter the pages to remove and download the edited file. At least one page must remain.

    Does splitting reduce the quality?

    No. Pages are copied without being re-rendered or recompressed, so quality is identical to the original.

    Why does it say my file is damaged?

    The file may be truncated, not a real PDF or password-protected. Try opening it in a PDF viewer first; if it opens there, re-save it and try again.

    Can I use it on my phone?

    Yes. It works in modern mobile browsers, although very large files are quicker on a computer.
