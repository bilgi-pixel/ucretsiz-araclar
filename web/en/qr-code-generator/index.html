Free QR code generator with logo, Wi-Fi and vCard support

QR codes have become part of everyday life: restaurant menus, Wi-Fi access for guests, event tickets, business cards and product packaging all rely on them. This free QR code generator creates codes for website links, plain text, Wi-Fi networks, contact cards, WhatsApp messages, emails, text messages and phone calls. You can add your own logo, choose colors, and download the result as a PNG for screens or an SVG for professional printing. Everything is generated in your browser, so the information you type is never uploaded.

Because the codes are static, there is no tracking, no redirect through a third-party domain and no expiry date. The data is encoded directly in the pattern, which means your code works forever, even if you stop using this website.

How to create a QR code

  1. Choose the QR code type, for example website link, Wi-Fi network or contact card.
  2. Fill in the form. The preview on the right updates instantly as you type, so you can see the code taking shape.
  3. Open Appearance settings to change size, margin, error correction and colors, or to add a logo in the center.
  4. Press Download PNG for a ready-to-use image or Download SVG for a vector file. You can also copy the image straight to the clipboard.
  5. Test the code with your phone camera before printing or sharing it.

QR code types explained

Website link or text. The simplest and most common option. Paste a full address starting with https:// and phones will offer to open it. Plain text works too, for example a serial number or a short message.

Wi-Fi network. Guests scan the code and join your network without typing a long password. Enter the network name exactly as it appears, select the security type and add the password. Choose Hidden network only if your router does not broadcast its name.

Contact card (vCard). Put your name, company, phone, email, website and address into a code. Scanning it offers to save you as a contact, which is perfect for business cards, conference badges and email signatures.

WhatsApp, email, SMS and phone. These codes start an action: opening a chat with a pre-filled message, writing an email with a subject and body, composing a text message, or dialing a number. Enter phone numbers with the country code, such as +1 for the United States or +44 for the United Kingdom.

Design tips for QR codes that actually scan

A QR code is a technical object first and a design element second. Keep a dark pattern on a light background, with a contrast ratio of at least 4 to 1. Inverted codes, with a light pattern on a dark background, are not read by many scanners, so the tool warns you if you choose them. Leave the quiet margin around the code, because scanners need empty space to find its edges. Four modules is the standard and a good default.

Error correction decides how much damage a code can survive. Level L recovers about 7 percent of the data, M about 15 percent, Q about 25 percent and H about 30 percent. Higher levels make the pattern denser, so keep the lowest level that serves your purpose. Choose H when you add a logo, because the logo hides some modules. Keep the logo to roughly a fifth of the code width and put a light plate behind it, which the tool does automatically.

Size matters too. Print the code at least 2 by 2 centimeters, and larger for anything people scan from a distance. A rough guide is one tenth of the scanning distance, so a poster scanned from two meters away should carry a code around 20 centimeters wide. When in doubt, download the SVG, which scales to any size without blur.

PNG or SVG?

PNG is a bitmap image, ideal for websites, slides, documents and social media. Pick a size large enough for where it will be displayed, such as 512 pixels for a typical web page. SVG is a vector file made of shapes instead of pixels, so it stays perfectly crisp whether it is printed on a business card or a billboard. Send the SVG to your print shop and they will thank you. Both formats are available with one click.

Privacy and safety

The generator runs in your browser and never sends the content of your code anywhere. That matters for Wi-Fi passwords and personal contact details. Remember, though, that anyone who scans a code sees what is inside it, so do not encode secrets in a code you plan to publish. Only scan codes from sources you trust, and be careful with codes on stickers placed over other codes, a known trick used to redirect people to fake websites.

Frequently asked questions

Is this QR code generator really free, and do the codes expire?

Yes, it is free and the codes never expire. These are static QR codes: the information is stored directly in the pattern, so there is no redirect service, no subscription and nothing that can be switched off later. A code you print today will keep working for as long as the link or text inside it remains valid.

Is my data sent to a server?

No. The QR code is generated entirely in your browser, so the Wi-Fi password, contact details or link you type never leave your device. We do not log the content and there is no account. You can disconnect from the internet after loading the page and the generator still works.

What size should I download for printing?

For a business card or flyer, 512 pixels is enough for sharp results at about 3 cm. For a poster or shop window choose 1024 or 2048 pixels, or download the SVG, which is a vector file that stays perfectly sharp at any size. As a rule of thumb, print the code at least 2 by 2 centimeters and leave the quiet margin around it.

Can I add my logo, and will it still scan?

Yes. Add a logo and the tool switches error correction to level H, which allows up to roughly 30 percent of the code to be covered or damaged. Keep the logo small, use a light background behind it and always test the finished code with at least two different phones before you print thousands of copies.

How do I make a Wi-Fi QR code?

Choose Wi-Fi network as the type, enter the exact network name, pick the security type, usually WPA, and type the password. Guests can then scan the code with the camera on iPhone or Android and join without typing. Passwords are case sensitive, so double-check capital letters.

Which QR code types are supported?

You can create codes for website links and plain text, Wi-Fi networks, contact cards in vCard format, WhatsApp messages with a pre-filled text, emails with subject and body, SMS messages and phone calls. Each type has its own form, and the code updates live as you type.

Why will my QR code not scan?

The most common reasons are low contrast, an inverted color scheme, a missing quiet margin, a code printed too small, or too much text. Use a dark pattern on a light background, keep the margin on, print at least two centimeters wide and shorten the content or use a short link if the code looks very dense.

Can I use the codes commercially?

Yes. The QR codes you create are yours to use on menus, packaging, business cards, posters or websites without attribution or fees. Please make sure the content you encode, such as a link, is yours to share and does not point people to anything harmful or misleading.
