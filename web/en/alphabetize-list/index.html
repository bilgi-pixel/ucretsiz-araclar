Alphabetize List – Sort Any List in Alphabetical Order Online

Paste your names, words, titles or any list with one item per line and put it in alphabetical order in a click. Sort A to Z or Z to A, remove duplicates and blank lines, and sort numbers by value. Your text never leaves your device.

How to alphabetize a list

  1. Paste or type your list into the box, with one item on each line. You can copy a column straight from a spreadsheet and paste it in.
  2. Leave the sort type on Alphabetical (A to Z), or tick Z to A for reverse order. Other choices sort by line length or simply flip the list upside down.
  3. Adjust the options if needed: ignore capital letters, remove duplicates, drop blank lines, and sort numbers by value so that 2 comes before 10.
  4. Press Sort list. The sorted result appears below with a short summary of how many lines were sorted and how many duplicates or blanks were removed.
  5. Press Copy list and paste the result wherever you need it, such as a document, spreadsheet, email or code file.

How alphabetical order really works

Alphabetical order compares two items letter by letter from the left. "Cat" comes before "Cow" because the first letters match and "a" comes before "o". A shorter word comes before a longer one that starts the same way, so "car" comes before "card". That sounds simple, but in practice lists contain capital letters, punctuation, accents and numbers, and different tools handle them differently. A basic computer sort, for instance, places every capital letter before every lowercase letter, which puts "Zebra" ahead of "apple". Most people do not expect that.

This tool uses your browser's language-aware collation instead, so "apple", "Apple" and "banana" are sorted the way a dictionary or index would sort them. With Ignore uppercase and lowercase ticked, differences in capitalization do not affect the order. Accented letters such as é or ü are placed next to their base letters, and the Turkish option follows the Turkish alphabet, where ç, ğ, ı, ö, ş and ü have their own places.

Sorting numbers the way people expect

If your list contains numbers, a plain text sort puts "10" before "2" because the character 1 comes before 2. That is correct for letters but wrong for quantities. Tick Sort numbers by value and the tool reads digit sequences as numbers, so Chapter 2 comes before Chapter 10, and file2.txt comes before file10.txt. This setting is useful for filenames, house numbers, episode titles, version labels and anything else that mixes words with numbers.

Typical uses for an alphabetizer

  • Bibliographies and reference lists. Many style guides, including APA and MLA, expect sources in alphabetical order by author surname. Put the surname first on each line, sort, and paste the list back.
  • Class rosters and guest lists. Teachers, event planners and coaches can sort names in seconds, and remove accidental repeats using the duplicate option.
  • Glossaries and indexes. Terms sorted A to Z are easier to scan and to cross-reference.
  • Keyword and tag lists. Marketers and bloggers can tidy up keyword research and drop repeated phrases.
  • Code and configuration. Developers sort imports, dependency names, CSS properties or environment variables so changes are easier to review.
  • Shopping and packing lists. Sorting a grocery list by name makes it quicker to cross-check against a store flyer.

Removing duplicates and blank lines

Lists copied from the web, an email thread or a spreadsheet often contain repeated entries and empty lines. Tick Remove duplicate lines to keep only the first occurrence of each item. When uppercase and lowercase are ignored, "Apple" and "apple" count as the same entry. If you need both versions, untick the case option. Blank lines are removed by default, and leading or trailing spaces are trimmed so that " apple" and "apple" are treated the same.

Sort by length and reverse order

Sometimes you want the shortest or the longest items first, for example when checking which headlines might be cut off in search results. Choose By line length and the shortest lines come first, with ties sorted alphabetically. Add Z to A to put the longest first. The Reverse the order of lines option simply flips the list without comparing anything, which is handy for reversing a chronological log.

Tips for better results

If your data lives in columns, copy a single column at a time, because each line is sorted as a whole. For names, decide in advance whether to sort by first name or by surname and format each line to match, such as "Smith, Anna". If you need to clean up capitalization afterward, the Case Converter can switch text to Title Case or lowercase, and the Word Counter will tell you how long your final list is. For random order instead of alphabetical, the Random Number Generator can help you draw items.

Private by design

The sorting happens entirely in your browser. Your list is not uploaded, stored or tracked, there is no account, and the page works offline once it has loaded. That makes it safe for client lists, email addresses and other private data.

Frequently asked questions

How do I alphabetize a list online?

Paste your list with one item per line, leave the sort type on Alphabetical (A to Z), and press Sort list. Then copy the sorted result with the Copy list button.

How do I sort Z to A?

Tick the Z to A (reverse order) box before pressing Sort list. The tool sorts alphabetically and then reverses the result.

Does the sorter treat uppercase and lowercase the same?

By default yes, so Apple and apple sit next to each other. Untick Ignore uppercase and lowercase if you want capitalization to break ties.

Why does 10 come before 2 in my list?

Text sorting compares character by character, and 1 comes before 2. Tick Sort numbers by value to compare the full numbers, so 2 comes before 10.

Can I remove duplicates while sorting?

Yes. Tick Remove duplicate lines and only the first copy of each item is kept. The summary tells you how many duplicate lines were removed.

How do I alphabetize names by last name?

Write each name with the surname first, for example Smith, Anna, then sort. If your names are in first-name-last-name order, rearrange them in a spreadsheet first.

Does it handle accented or non-English letters?

Yes. Accented letters are sorted next to their base letters, and the Turkish alphabet option applies Turkish ordering for letters such as ç, ğ, ı, ö, ş and ü.

Is there a limit to the list size?

There is no fixed limit. Lists with tens of thousands of lines sort quickly, though extremely large pastes depend on your device memory.

Is my list uploaded to a server?

No. Sorting runs entirely in your browser, and nothing is uploaded, stored or tracked.
