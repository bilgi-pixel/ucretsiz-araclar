Our privacy promise

The tools on this site never send your files to a server. It is not even technically possible: the pages are published as static files, and there is no backend that accepts uploads. You can disconnect from the internet after the page loads and keep working. The only third-party code on the page is the advertising script that pays for hosting; it never sees your files.

Frequently asked questions

Is it really free? Is there a limit?

Yes, completely free. There is no file count, file size or daily limit. The only limit is your browser's memory: very large files (hundreds of megabytes) may be slow on older devices.

Where do my files go?

Nowhere. The file is opened in your browser's memory, processed there, and the result is downloaded back to your device. When you close the tab, the memory is cleared.

Does it work on a phone?

Yes. It works in Android and iPhone browsers (Chrome, Safari). A computer is faster for large files.

Can I install it on Windows or Mac?

Yes. Use your browser's "Install app" option to get an icon, a window of its own and offline use. No installer download is required.

Why is it free?

We at Bilişim Ajans use these tools in our own work every day. We wanted an alternative that anyone can use safely without creating an account. Advertising covers the domain and development costs.

Can I see the code?

Yes, all source code is public on GitHub. You can review it, report bugs or contribute.
