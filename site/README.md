# WordPress (bilisimajans.com) içerikleri

Ana site WordPress.com'da; araçlar ayrı alt alanda (`araclar.bilisimajans.com`, GitHub Pages).
Buradaki dosyalar WordPress yönetim paneline elle girilir.

- `menu.md` — "Ücretsiz Programlar" menü öğeleri ve bağlantıları.
- `ucretsiz-programlar.md` — WordPress'te açılacak tanıtım sayfası metni.

AdSense kodu bu WordPress sitesine **eklenmez** (WordPress.com planı gerektirir); reklamlar
yalnızca alt alandaki araç sayfalarında.
